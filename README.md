# ARIE Phase 1 Reproducibility Pack

ARIE provides an audit-first reproducibility pack for Phase 1 evidence regeneration.
The default path regenerates JSON/CSV/Markdown artifacts that support review of data coverage, concordance, plausibility scoring, and abstention policy behavior.
The run is orchestrated by `scripts/repro_pack.py` and recorded in a hash-based manifest.

## Quickstart (clean clone)

```bash
git clone https://github.com/Xyloth/arie-phase1-repro-pack.git
cd arie-phase1-repro-pack
python -m venv .venv
./.venv/bin/pip install -r requirements.txt
```

Required local input (not committed):
- Place `Crumb_Extraction.txt` in repo root.
- Also accepted: any filename containing `crumb_extraction` (case-insensitive) in repo root or `raw/`.
- This file is manual text transcription from PDF tables and is not redistributed in this repository.

Required precomputed prediction inputs:
- `results/calibration_predictions.csv`
- `results/ood_knn_scores.csv`

If missing, generate them:

```bash
./.venv/bin/python scripts/run_calibration.py
./.venv/bin/python scripts/run_ood_knn.py
```

Run the reproducibility pack:

```bash
./.venv/bin/python scripts/repro_pack.py
```

If the two prediction prerequisites already exist, skip the generation step and run only `scripts/repro_pack.py`.

## What this proves

The evidence pack is reproducible and auditable: one workflow regenerates the same artifact set and the manifest records per-file SHA256 hashes and CSV row counts so reruns can be compared directly.

## Data provenance

Default repro path:
- ChEMBL multichannel data is fetched by `scripts/fetch_mechanistic_multichannel_chembl.py`.
- ChEMBL cache is written under `data/cache/chembl_multichannel/`.
- ChEMBL licensing note: CC BY-SA.

Optional helpers (not required by default `scripts/repro_pack.py`):
- `scripts/download_cipa_data.py` downloads CiPA Blinova data from [https://cipaproject.org/data-resources/](https://cipaproject.org/data-resources/) to `data/raw/cipa_blinova_2018/` and writes `data/cache/cipa_blinova_2018.json`.
- `scripts/download_mechanistic_data.py` downloads OSF hERG data from [https://osf.io/a6k5t/](https://osf.io/a6k5t/) to `data/raw/herg_multilab_2025/` and writes `data/cache/herg_multilab_2025.json`.
