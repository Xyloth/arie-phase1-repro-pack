# ARIE Phase 1 Evidence Reproducibility Pack

This repository reproduces ARIE Phase 1 evidence as audit-ready JSON/CSV/Markdown artifacts.
It is designed for traceability and reproducibility review, not graph generation.
The default workflow is `scripts/repro_pack.py`, which records outputs and hashes in a manifest.

## Quickstart (clean clone)

```bash
git clone https://github.com/Xyloth/arie-phase1-repro-pack.git
cd arie-phase1-repro-pack
python -m venv .venv
./.venv/bin/pip install -r requirements.txt
```

## Required local input (NOT committed)

- Place `Crumb_Extraction.txt` in repo root.
- Accepted by parser: any filename containing `crumb_extraction` (case-insensitive) in repo root or `raw/`.
- This file is a manual text extraction from published tables and is not redistributed in this repository.

## Required prediction prerequisites

- `results/calibration_predictions.csv`
- `results/ood_knn_scores.csv`

If missing, generate them:

```bash
./.venv/bin/python scripts/run_calibration.py
./.venv/bin/python scripts/run_ood_knn.py
```

If both files already exist, skip generation and run the reproducibility pack directly.

## Run

```bash
./.venv/bin/python scripts/repro_pack.py
```

## What this proves

The workflow regenerates a fixed evidence set and emits a manifest with SHA256 hashes and CSV row counts, providing an auditable trail for reproducibility checks.

## Data provenance & licensing

Default repro path:
- ChEMBL is fetched by `scripts/fetch_mechanistic_multichannel_chembl.py`.
- ChEMBL cache is written under `data/cache/chembl_multichannel/`.
- ChEMBL licensing note: CC BY-SA.

Optional helpers (not required by default repro run):
- `scripts/download_cipa_data.py` downloads CiPA Blinova source data from [https://cipaproject.org/data-resources/](https://cipaproject.org/data-resources/) and caches metadata under `data/cache/`.
- `scripts/download_mechanistic_data.py` is available for OSF hERG ingestion but is not required by `scripts/repro_pack.py`.
